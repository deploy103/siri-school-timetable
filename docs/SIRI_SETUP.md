# Siri 단축어 설정

이미지와 함께 보는 학생용 안내는 서비스 안 `/guide` 페이지를 참고한다. 이미지 준비 방식은 [docs/GUIDE_ASSETS.md](GUIDE_ASSETS.md)에 있다.

웹사이트가 Siri 기능을 자동 등록할 수는 없다. 사용자가 Apple 단축어 앱에서 개인용 단축어를 만들어야 한다. 사이트의 **Siri 설정** 화면은 현재 학교 설정이 포함된 시간표·급식 음성 API URL과 아래 절차를 제공한다.

## iPhone에서 설정

1. 웹사이트에서 학교·학년·반을 저장하고 **Siri 설정**을 누른다.
2. 만들 기능에 맞춰 **시간표 URL 복사** 또는 **급식 URL 복사**를 누른다.
3. iPhone의 **단축어** 앱에서 `+`로 새 단축어를 만든다.
4. **URL** 동작을 추가하고 복사한 주소를 붙여 넣는다.
5. **URL 콘텐츠 가져오기** 동작을 추가한다. 메서드는 `GET`이며 헤더나 요청 본문은 필요 없다.
6. **텍스트 말하기** 동작을 추가하고 입력을 앞 동작의 결과로 둔다.
7. 시간표 URL은 `오늘 학교 시간표 뭐야`, 급식 URL은 `오늘 학교 급식 뭐야`라는 이름으로 저장한다.
8. “시리야, 오늘 학교 시간표 뭐야?” 또는 “시리야, 오늘 학교 급식 뭐야?”라고 말해 확인한다.

두 기능을 모두 쓰려면 위 절차를 URL별로 한 번씩 반복해 단축어 두 개를 만든다. 급식 단축어는 칼로리·영양·원산지·알레르기 번호를 읽지 않고 메뉴만 간결하게 말한다.

음성 엔드포인트는 JSON이 아니라 `text/plain; charset=utf-8`을 반환하므로 사전 추출이나 JSON 파싱 동작이 필요 없다.

## URL 보안 특성

시간표 URL에는 교육청 코드, 학교 코드, 학교 종류, 학과(선택 시), 학년, 반이 들어간다. 급식 URL에는 교육청 코드와 학교 코드만 들어간다. NEIS API 키, 사용자 이름, 기기 식별자나 인증 토큰은 들어가지 않는다. URL이 노출되어도 서버의 NEIS 키는 노출되지 않으며 Rate Limit이 적용된다.

## 공유 단축어에 관하여

Apple의 iCloud 링크 공유는 사용자가 단축어 앱에서 직접 공유를 활성화하는 흐름이다. 서버가 신뢰할 수 있는 iCloud 공유 링크를 동적으로 발급하거나, 웹사이트가 임의의 단축어를 조용히 설치할 수 있는 공식 API는 없다. 이 프로젝트는 서명되지 않은 `.shortcut` 파일이나 비공식 URL scheme을 만들지 않는다. 설정별 URL이 다르므로 MVP에서는 위의 수동 설정을 사용한다.

## 문제 해결

- Siri가 이름을 못 알아들으면 단축어 앱에서 단축어를 직접 실행해 네트워크 응답부터 확인한다.
- 시간표나 급식을 가져올 수 없다는 안내가 들리면 잠시 뒤 재시도하고 웹 화면에서도 같은 설정으로 조회되는지 확인한다.
- 학교를 바꾸면 웹사이트에서 새 URL을 복사해 기존 **URL** 동작을 교체한다.
- 로컬 개발 주소는 iPhone에서 접근할 수 없을 수 있다. 실제 Siri 사용에는 iPhone에서 HTTPS로 접근 가능한 배포 주소가 필요하다.
