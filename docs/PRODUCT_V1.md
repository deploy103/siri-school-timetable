# 오늘의 학교 — 학생 v1 제품 계획

기준일: 2026-10-21 KST. 실제 수신한 비동기 에이전트 제품 검토 기록이며 학생 인터뷰 결과가 아니다. 소유자가 승인한 Notion 게시 목적지는 기존 **main → 서비스 개발 → 오늘의 학교**다. 아래 새 인계가 이전 진행 중 상태보다 우선한다. 결정 경위는 [검토 기록](meetings/2026-10-21-student-v1.md)을 참조한다.

## 수신한 결정·증거 갱신

- coordinator는 UX 방향을 수락했다. 기존 ‘준비’를 다가오는 일정/날짜 모드로 확장하고 미완료를 기한 지남·오늘·다음 7일·이후로 구분하며 완료 항목은 접는다. 완료와 편집은 별도 동작이다. `kind`는 `item/deadline`을 유지하고 선택적 `assessment/exam/homework` 분류 및 선택적 notes를 추가한다. 직접 입력은 무료이고 학교·반 선택 후 시간표 자료를 받지 못해도 쓸 수 있다. 이는 소스만 본 UX 권고를 수락한 것이지 학생 인터뷰/사용성 검증 결과가 아니다.
- 평가 분류·메모·다가오는 일정과 선생님 메모 설정 진입을 구현했다. 구형 v1/v2 기록은 기존 ID·완료 상태·미분류 마감을 보존해 읽는다. 새 저장은 schema 3이며 파일명은 유지한다. 구버전 앱이 새 분류·메모를 무시하고 재저장하지 못하도록 버전으로 거부하게 하는 선택이다. 되돌려 설치한 구버전 앱에서는 새 기록을 열 수 없으므로 업데이트가 필요하다. 현재 표시 브랜드와 가격은 변경하지 않는다.
- 부모 통합 검사: Linux Foundation **37/37**, 웹 Vitest **194/194**, typecheck/lint 통과. Playwright 1.63 컨테이너 Chromium 390/768/1440 및 iPhone WebKit에서 **24/24 통과**했다. 처음 network-none 컨테이너의 재연결 4개 실패는 보존했다. 네트워크 인터페이스를 제공한 같은 테스트에서 4개 통과 후 전체 24개를 재실행했다. 학교·급식·음성 응답은 예제 모드이며 실운영 API 검증이 아니다.
- 교사 메모는 로컬 전용 수동 과목/이름/교실/메모, 학교+학급 격리, 손상/미래 archive fail-closed다. 설정에 통합했으며 준비 백업·수동 iCloud·학교 설정 공유·위젯에는 포함하지 않는다. 이 제한을 설정에 표시한다. 새 네이티브 snapshot `5264901d…`의 실제 빌드·타입 검사 및 hosted unit **38/38** 통과 보고를 수신했다(기존 35 + 메모 3). 새 UI 검사는 진행 중이며 완료·시각 승인으로 올리지 않는다.
- native verifier의 정리 완료·자원 해제 보고: **2026-10-21 06:26:00 UTC (15:26:00 KST)**. UIv3 SHA-256 `a29d83c24381520fa1ec2d0201ea66e2ba76852026c4717f87e5892400a712fa`, unit snapshot `05c0`은 변경 없음. 동일 설치 identity, 전체 62개 source gate 조건에서 **오직 `testRedesignedCalendarPreparationOptionsAndPlusCatalog` 1/1 PASS, 실패 0, 189.249초**다. 62개 실행 통과라는 뜻이 아니다.
- **검증자 정정:** 로그에 Boolean 값이 없어 pending-with-products와 completed-catalog를 구별할 수 없다. 앞선 completed-CATALOG 판정은 철회한다. 상품/refresh 조회와 가격 안전 predicate 통과, retry 미실행, 실제 Close → OS Files navbar 및 enabled+hittable action button → 실제 sheet drag/dismissal → exporter 복귀만 확인했다. StoreKit unit recovery·운영 lifecycle·새 메모/평가 코드·실물 기기는 이 v3 검사로 검증하지 않았다. 이전 v2 및 unit 빈 카탈로그 실패는 유지한다. 캡처는 보존되었으나 media quota 때문에 시각 검토 불가: 시각적 승인으로 해석하지 않는다.
- **07:09 UTC 부모 갱신:** student-v1은 빌드/hosted 38개와 기존 날짜 UI·최대 글자 dark UI 각 1개를 통과했고 새 평가/메모 UI는 1개 실패로 종료했다. 제목 입력 후 과목 hittability에서 막혀 저장·완료·메모 UI·재실행은 도달하지 않았다. 저장 AX가 앱 노드 하나뿐이라 가림 원인은 확정하지 않았다. 실제 SDK 해제는 06:58:24 UTC다. 부모가 94 MiB 근거 묶음의 SHA-256 `5b3b05a0…`, 577개 checksum, 64 source 및 26 binary 기록과 40 PASS/1 FAIL 보존을 Linux에서 독립 확인했다. 39개 캡처는 미검토다.
- **후속 구현·검증 대기:** 키보드 위 ‘입력 완료’·필드 다음 이동·스크롤 해제, 실패 시 AX 진단, 별도 NEIS 학사일정 주간 화면과 읽기 전용 서버를 추가했다. 학교 원문과 직접 적은 평가는 분리하며 빈 일정/학년 flag로 휴일을 추측하지 않는다. 서버는 17개 학사일정 사례를 포함한 Vitest 211/211·lint/typecheck/build, Linux Foundation은 40/40 통과했다. 구독 구현을 바꾸지 않고 SKTestSession 설정 전 store 초기화를 막는 테스트 전용 독립 호스트를 추가했다. 정확한 후속 67-file archive `cbbb37ff…`를 Mac 검증자에게 전달했고 iOS 원본은 동결했다. 이 후속 소스의 native/UI/lifecycle 통과는 아직 없다. 운영 배포·실제 구매는 하지 않았다.

아래 초기 소스 관찰/백로그는 이 수신 기록으로 완료 범위를 제한해 읽는다. 가격(월 ₩1,100/연 ₩9,900), 광고, 대체 이름은 **미결정·미게시 제안**이며 이 내부 기록 게시가 제안 승인/외부 광고 게시를 의미하지 않는다.

## 제품 방향과 확정 경계

- 네이티브 iOS가 주 제품이다. 오늘·주간 시간표, 급식, Siri 기본 흐름을 유지한다. 웹은 백엔드와 진입·설정 안내를 지원하며 iOS 설치를 대신하지 않는다.
- 수행평가·시험·숙제를 직접 분류하고 상세 내용과 다가오는 일정을 확인하는 기본 흐름은 무료로 추가한다. 학교가 자동 제공하는 공식 평가 일정이라고 표시하지 않는다.
- 교사·과목 메모는 사용자가 직접 쓰는 비공개 개인 기록이다. 공개 인명 디렉터리·교사 평가·연락처 수집을 만들지 않는다.
- 학교 전체 공개 UGC는 작성자 확인, 신고·차단·검수, 삭제·보존 및 미성년자 개인정보 설계가 마련될 때까지 보류한다.
- 학교 설정·시간표 공유에 개인 메모나 완료 상태가 섞이면 안 된다. 가격·브랜딩·공유 확장은 별도 승인 대상이다.
