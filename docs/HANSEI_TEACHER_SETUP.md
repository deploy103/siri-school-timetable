# 한세 교사용 시간표 설정

한세사이버보안고등학교 교사용 화면은 메인 화면에 노출되지 않는 별도 경로 `/hansei-t`에서 제공한다. 운영 주소가 `https://time.mvtp.cloud`라면 접속 주소는 다음과 같다.

```text
https://time.mvtp.cloud/hansei-t
```

이 페이지에는 검색 엔진용 `noindex, nofollow` metadata가 적용되어 있지만 인증 화면은 아니다. 주소를 아는 사용자는 접근할 수 있다.

## 처음 설정하기

1. `/hansei-t`에 직접 접속한다.
2. 고정된 학교가 **한세사이버보안고등학교**인지 확인한다.
3. NEIS의 현재 학기 시간표에서 수집된 **담당 과목**을 하나 이상 선택한다.
4. 과목별 후보 중 본인이 실제 담당하는 **학과·학년·반**만 선택한다. 후보는 기본으로 선택되지 않는다.
5. 여러 과목을 담당해 음성에서 과목 구분이 필요하면 **음성에 과목명 포함**을 켠다.
6. **설정 저장**을 눌러 오늘 수업을 확인한다.

설정은 `time-siri.teacher-settings.v1`이라는 별도 `localStorage` 항목에 저장된다. 학생용 학교 설정과 섞이지 않으며 교사 이름은 저장하거나 전송하지 않는다. **설정 변경**으로 다시 선택할 수 있고 **설정 초기화**로 교사용 설정만 지울 수 있다.

## 담당 학급을 직접 고르는 이유

NEIS 고등학교 시간표에는 담당 교사를 확실히 구분하는 teacher ID가 없다. 같은 과목을 여러 교사가 가르칠 수 있으므로 과목 이름만 같은 모든 수업을 한 선생님의 수업으로 간주하면 안 된다.

이 서비스는 다음 네 값이 모두 일치할 때만 담당 수업으로 판정한다.

```text
과목 + 학과 + 학년 + 반
```

과목·학과명은 Unicode와 공백을 보수적으로 정리한다. 학과는 한세에서 쓰는 알려진 표기 차이만 alias로 연결하고, 과목은 서로 다른 과목을 합칠 수 있는 공격적인 fuzzy matching을 하지 않는다. NEIS의 원본 학과명은 설정 profile 안에 보존한다.

같은 교시에 완전히 같은 행이 반복되면 하나로 합치지만, 서로 다른 담당 학급이 같은 교시에 잡히면 하나를 버리지 않는다. 웹 화면에 모든 충돌 수업을 표시하고 Siri도 해당 교시에 확인이 필요하다고 안내한다.

## Siri 설정

오늘 수업 화면에서 **Siri 설정**을 누르고 교사용 API URL을 복사한다. iPhone의 단축어 앱에서 다음 순서로 만든다.

1. 단축어 앱에서 새 단축어 생성
2. **URL** 동작 추가 후 복사한 주소 붙여넣기
3. **URL 콘텐츠 가져오기** 추가, 메서드는 `GET`
4. **텍스트 말하기** 추가
5. 단축어 이름을 **학교 수업**으로 저장

호출 문구:

```text
시리야, 학교 수업
```

정상 응답 예:

```text
9월 23일 오전 9시 23분 조회 기준, 2교시 클보 1학년 2반, 3교시 클보 2학년 1반, 4교시 게임과 2학년 1반 수업이 배정되어 있습니다.
```

`조회 기준`은 NEIS가 자료를 마지막으로 수정한 시각이 아니라 우리 서버가 NEIS 자료를 조회한 시각이다.

## 변경 시간표와 캐시

- Siri와 웹의 오늘 시간표 요청은 매번 오늘 날짜를 기준으로 처리한다.
- `/hansei-t` 오늘 수업 화면은 열어 둔 동안 30분마다 자동 새로고침하며, 백그라운드에 있던 화면으로 돌아왔을 때 마지막 시도 후 30분이 지났으면 즉시 다시 조회한다.
- 같은 학교의 동시·반복 요청 폭주를 막기 위해 오늘 전체 시간표만 60초간 서버 메모리에 캐시한다.
- 과목과 학급 후보는 현재 학기 안의 최소 8주 범위를 조회하고 6시간 캐시한다.
- 범위 조회는 NEIS의 `list_total_count`를 확인하고 `pSize=1000`으로 끝 페이지까지 가져온다.
- NEIS 조회가 실패하면 오래된 오늘 시간표를 대신 반환하지 않는다.

## 장애 대응

- `현재 학교 시간표 정보를 확인할 수 없습니다`: NEIS 상태, 서버 네트워크, `NEIS_API_KEY`를 확인하고 잠시 뒤 다시 시도한다.
- `요청이 너무 많습니다`: `Retry-After` 이후 다시 시도한다. 신뢰 가능한 reverse proxy 환경에서는 `TRUST_PROXY_HEADERS=true` 설정도 확인한다.
- `교사용 시간표 설정이 올바르지 않습니다`: `/hansei-t`에서 설정을 다시 저장하고 단축어의 URL도 새 URL로 교체한다.
- 수업 없음: 주말·휴업일·미게시일 또는 실제 무수업일을 모두 정상 빈 결과로 안내한다.

## NEIS 자체의 한계

NEIS가 제공하지 않는 교사 ID, 실제 교사 배정, 학교 내부의 미게시 변경 사항은 이 서비스가 알아낼 수 없다. 설정한 네 필드가 정확히 일치하는 행만 선택해 다른 교사의 수업을 포함할 가능성을 줄이지만, 원천 시간표 입력이 잘못되었거나 아직 갱신되지 않은 경우까지 보정할 수는 없다.
